# 从实验室到每个人的窗口：浏览器发展史

浏览器是互联网的入口，也是万维网走向大众的载体。它的三十余年，几乎就是**互联网从少数人走向所有人、从静态文档走向实时应用**的历史。

**1990 年，第一个浏览器诞生。** 欧洲核子研究组织的蒂姆·伯纳斯-李在 NeXT 工作站上写出 **WorldWideWeb**，它既能浏览文档也能编辑网页，却只在少数研究者的屏幕上亮过。

**1993 年，Mosaic 让万维网"看起来像互联网"。** 它第一次把图片直接嵌进文字之间，网页从此不再只是枯燥的文本列表。次年，Mosaic 的核心成员马克·安德森创办网景公司，推出 **Netscape Navigator**，一度占据九成市场，成为一代人上网的入口。

**1995 年，第一次浏览器大战爆发。** 微软发布 Windows 95，把 **Internet Explorer 直接捆绑进操作系统**。战争持续数年，结局是网景落败并于 1998 年开源代码，IE 凭捆绑优势登顶。

**垄断带来的是停滞。** 此后数年，IE 长期领先、更新缓慢，网页标准推进艰难。转机出现在开源社区：网景的代码演化为 Mozilla 项目，**2004 年 Firefox 问世**，用标签页、扩展和安全重新点燃竞争；2003 年苹果推出 **Safari**，基于 KHTML 打造 WebKit。

**2008 年，Chrome 重新定义浏览器。** 谷歌发布 **Chrome**，以 V8 引擎和"每个标签页一个进程"的架构，把速度与稳定性推到前所未有的高度。第二次大战胜负很快分明：Chrome 以开源项目 **Chromium** 为底座，吸引大量厂商跟进，**连微软也在 2020 年放弃自研内核**，让 Edge 转向 Chromium。

**浏览器开始被称作"新的操作系统"。** HTML5 逐步取代 Flash 等插件，网页能直接播放视频、绘制图形、运行应用；**WebAssembly** 的出现，更让接近原生性能的程序跑进了网页里。

代价也随之而来：当几乎所有浏览器共享同一套渲染引擎，标准的话语权便高度集中，**"开放"与"垄断"的边界变得模糊**。回望三十余年，浏览器从实验室里的一件工具，变成承载搜索、社交、办公与娱乐的通用平台——而这场关于入口的竞争，远未结束。
